# 🔧 6. コアコンポーネント

## TranslationService（`app/translation_service.py`）
- 役割: 入力の保護（`protect_text`）→ Provider 呼出 → 復元（`restore_text`）のパイプラインを提供
- 公開メソッド: `translate_text`, `translate_embed`, `translate_message`
- 特徴: `max_concurrent`（同時翻訳上限）をサポート、`ProviderError` による一貫した例外処理

## Provider（`app/providers/*`）
- インターフェース: `Provider`（`translate` / `translate_async` の契約）
- 実装例:
  - `DeepLProvider` — `deepl` SDK を遅延インポートして利用
  - `GoogleProvider` — `googletrans` をラップして非同期から呼べるように実装

## Markdown ユーティリティ（`app/utils/markdown_helper.py`）
- 保護対象: コードブロック、インラインコード、メンション、URL、カスタム絵文字
- 手順: トークン化 → Provider に渡す → トークン復元
- 衝突対策: プレースホルダにユニークサフィックスを付与

## Bot / コマンド層
- `app/deeplTrans.py` / `app/googleTrans.py` — 既存互換のエントリポイント（内部で `TranslationService` を呼ぶ）
- `app/commands/translate_commands.py` — `/add_channel`, `/set_provider`, `/show_config` 等のスラッシュコマンド

## テスト戦略（要旨）
- Provider は外部API呼び出しをモックして単体テスト
- `TranslationService` は保護・復元・Provider 選択ロジックを網羅するテストを用意
- 追加テストファイル: `tests/test_translation_pipeline.py`, `tests/test_*_provider.py`, `tests/test_embed_translation.py`
