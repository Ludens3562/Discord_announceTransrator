# 📖 1. 概要

## プロジェクト目的
Discord のメッセージ（本文・Embed・Markdown）を安全に翻訳して返信する Bot を提供します。単一サーバ／単一チャンネル前提の既存設計を改め、**マルチギルド／マルチチャンネル対応**かつ**翻訳プロバイダー（DeepL / Google）を切替可能**な設計へリファクタしました。

## 主要機能
- メッセージ本文・Embed（title/description/fields/footer）・Markdown（コードを保護）の翻訳
- Provider 抽象化（`GoogleProvider` / `DeepLProvider`）による動的切替
- guild/channel 単位でのプロバイダー上書き（`/set_provider`）
- 既存設定との互換性維持＋移行サポート

## 技術スタック
| 項目 | 内容 |
|---|---|
| 言語 | Python 3.10+ |
| Discord ライブラリ | discord.py |
| 翻訳プロバイダー | DeepL API（deepl）, googletrans |
| テスト | pytest |
| コンテナ化 | Docker / docker-compose |

## アーキテクチャパターン
- レイヤード＋プラグイン（Provider 戦略パターン）
- 翻訳処理は `TranslationService`（パイプライン）へ集約し、Bot 層はイベント/コマンド処理に専念します。
