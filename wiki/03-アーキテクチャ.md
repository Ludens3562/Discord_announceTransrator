# 🏗️ 3. アーキテクチャ

## 全体図 (Mermaid)

```mermaid
flowchart LR
  User[Discord ユーザー] -->|投稿| Bot[Discord Bot]
  Bot --> Events[イベントハンドラ/コマンド]
  Events --> TranslationService[TranslationService]
  TranslationService -->|選択| ProviderRegistry{Provider}
  ProviderRegistry --> DeepL[DeepLProvider]
  ProviderRegistry --> Google[GoogleProvider]
  DeepL -->|HTTP| DeepLAPI[(DeepL API)]
  Google -->|HTTP| GoogleAPI[(Google 翻訳API/googletrans)]
  TranslationService --> Config[設定ストア (config.json)]
  Bot -->|管理| Commands[/スラッシュコマンド/]
```

## コンポーネント説明
- `app/bot.py` — 共通の Bot インスタンス定義（Intents 管理）
- `app/commands/*` — スラッシュコマンド実装（管理者用コマンド含む）
- `app/translation_service.py` — 翻訳パイプライン（保護→翻訳→復元）
- `app/providers/*_provider.py` — 翻訳プロバイダー実装（プラグイン）
- `app/utils/markdown_helper.py` — Markdown の保護/復元ユーティリティ
- `app/deeplTrans.py`, `app/googleTrans.py` — 既存のエントリ／互換ラッパー

## 設計上のポイント
- Provider は `Provider` インターフェースに準拠し差し替え可能
- Markdown のコード・URL・メンションは保護して翻訳精度と安全性を担保
- guild/channel の設定で Provider を切替可能（優先度: channel > guild > global）
