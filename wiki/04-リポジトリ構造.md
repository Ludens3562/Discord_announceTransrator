# 📁 4. リポジトリ構造

```
Discord_announceTransrator/
├─ app/
│  ├─ bot.py                      # 共通 Bot インスタンス
│  ├─ deeplTrans.py               # DeepL エントリ・TranslatorBot（既存互換）
│  ├─ googleTrans.py              # Google エントリ（互換ラッパー）
│  ├─ translation_service.py      # 翻訳パイプラインの中核
│  ├─ utils/
│  │  └─ markdown_helper.py       # Markdown 保護・復元
│  ├─ providers/
│  │  ├─ provider.py              # Provider 抽象（インターフェース）
│  │  ├─ deepl_provider.py        # DeepL 実装
│  │  └─ google_provider.py       # Google 実装
│  └─ commands/
│     └─ translate_commands.py    # スラッシュコマンド実装
├─ tests/                         # pytest テスト群
├─ docs/                          # 補助ドキュメント（translation/migration）
├─ wiki/                          # プロジェクト Wiki（このディレクトリ）
├─ Dockerfile
├─ requirements.txt
└─ README.md
```

- 重要: 翻訳ロジックは `TranslationService` に集約し、`providers/*` を注入して使います。
- コマンドは `app/commands/` に分離して可読性を向上させました。
