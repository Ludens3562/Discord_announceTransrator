# 🗄️ 5. データモデル

## 永続データ概要
本プロジェクトではデータベースは使わず、JSON ファイルで軽量に永続化しています。

- `config.json` — Bot の設定（言語、デフォルトプロバイダー、guild/channel のプロバイダ上書きなど）
- `channels.json` — 監視対象チャンネルのマッピング（`{ "<guild_id>": ["<channel_id>", ...], ... }`）

### `config.json`（主要フィールド例）
```json
{
  "source_lang": "EN",
  "target_lang": "JA",
  "formality": "more",
  "default_provider": "deepl",
  "guild_providers": { "123456789": "google" },
  "channel_providers": { "987654321": "deepl" }
}
```

### `channels.json`（例）
```json
{
  "111111111111": ["22222222222", "33333333333"],
  "444444444444": ["55555555555"]
}
```

## リレーションと優先順位
- Provider の決定優先度: channel > guild > global (`default_provider`)
- `channels.json` は監視対象の「有効/無効」を決めるために使用

## 備考
- API キーは `.env` / 環境変数で管理し、設定ファイルには書き込みません。
