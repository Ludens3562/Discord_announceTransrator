# 📦 9. デプロイメント

## 環境変数（必須／推奨）
- `BOT_TOKEN` — Discord Bot トークン（必須）
- `DEEPL_API_KEY` — DeepL API キー（推奨）
- `GOOGLE_API_KEY` — Google（任意）
- `DEV_GUILD_ID` — 開発用ギルド ID（オプション、コマンド同期短縮用）

## Docker
1. ビルド
```bash
docker build -t discord-translator .
```
2. 実行
```bash
docker run -e BOT_TOKEN=... -e DEEPL_API_KEY=... discord-translator
```

## 運用上の注意
- 並列翻訳の上限は `TranslationService(max_concurrent=...)` で制御してください。
- API キーのレート制限やコストに注意（DeepL のクォータ監視を実装済み）
- 本番では `DEEPL_API_KEY` を Secrets 管理（Git に含めない）

## トラブルシューティング
- Bot が起動しない: `BOT_TOKEN` / intents（message_content）が設定されているか確認
- 翻訳が失敗する: Provider の API キーが有効か、`/show_config` で確認
