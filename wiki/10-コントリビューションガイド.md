# 🤝 10. コントリビューションガイド

## コーディング規約（重要）
- コメントとユーザー向けメッセージは日本語で記述すること（リポジトリ方針）
- 関数／クラスは単一責任（SRP）に従うこと
- テストを必ず追加する（特に Provider や翻訳の変換ロジック）

## ブランチ戦略
- 機能追加: `feature/<issue>-<short>`
- バグ修正: `fix/<short>`
- リリース: `release/<version>`

## PR チェックリスト
- [ ] テストが全て通る（`pytest`）
- [ ] 日本語コメントが適切に記載されている
- [ ] 既存の振る舞いを壊していない（後方互換性）
- [ ] docs または wiki を更新（必要時）

## 開発環境セットアップ（短縮）
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
```
