# 🚀 2. クイックスタート

## 前提条件
- Python 3.10+ がインストールされていること
- 環境変数: `BOT_TOKEN`（必須）、`DEEPL_API_KEY`（推奨）、`GOOGLE_API_KEY`（オプション）

## ローカルセットアップ（最短手順）
1. リポジトリをクローン／チェックアウト

   ```bash
   git clone <repo-url>
   cd Discord_announceTransrator
   git checkout feature/translation-pipeline-and-providers
   ```

2. 依存パッケージをインストール

   ```bash
   python -m pip install -r requirements.txt
   ```

3. 環境変数を設定（Windows の例）

   ```powershell
   setx BOT_TOKEN "your_bot_token"
   setx DEEPL_API_KEY "your_deepl_key"
   ```

4. BOT を起動（DeepL を使う例）

   ```bash
   python -m app.deeplTrans
   ```

## 動作確認
- 管理者権限で `/add_channel` を実行して対象チャンネルを追加
- 対象チャンネルに英語のメッセージを投稿 → Bot が翻訳して返信することを確認

## テスト実行
```bash
python -m pytest -q
```

## Docker 実行（簡易）
```bash
docker build -t discord-translator .
docker run -e BOT_TOKEN=... -e DEEPL_API_KEY=... discord-translator
```

（詳細は `docs/translation.md` と `docs/migration.md` を参照）
