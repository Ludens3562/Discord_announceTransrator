# リポジトリ構造
ディレクトリ構成と各ファイルの責務を示す。パスはリポジトリルートからの相対パスである。

## ディレクトリ構成
主要なディレクトリとファイルを次に示す。

```text

│   ├── bot.py                    TranslatorBot（Discord イベントと初期化）
│   ├── message_handler.py        監視メッセージの翻訳と返信（純粋関数）
│   ├── translation_service.py    翻訳パイプライン（TranslationService）

│   ├── commands/                 スラッシュコマンド定義
│   │   ├── __init__.py
│   │   └── translate_group.py    /translate コマンドツリー
│   ├── providers/                翻訳プロバイダー実装
│   │   ├── __init__.py           Provider / ProviderError を公開
```

## 各ディレクトリの責務
ディレクトリ単位の役割を次に示す。

- `app/`: アプリケーション本体。`python -m app.main` で起動する。
- `app/commands/`: Discord のスラッシュコマンド定義。コマンドツリーを構築する。
- `app/providers/`: 翻訳エンジンの実装。`Provider` 抽象を実装したクラスを配置する。
- `app/db/`: PostgreSQL への接続とデータアクセス。プール生成、スキーマ初期化、リポジトリ、データモデルを含む。
- `app/utils/`: 横断的なユーティリティ。翻訳前の Markdown 保護と、コマンドの権限チェックを提供する。
- `tests/`: pytest による単体テスト。外部依存はフェイクで代替する。
- `docs/`: ドキュメント。`docs/wiki/` に開発者向けドキュメントを配置する。

## 設定ファイル
設定に関わるファイルを次に示す。

- `app/.env.example`: 環境変数のテンプレート。`app/.env` にコピーして使用する。
- `requirements.txt`: Python の依存関係とバージョンを固定する。
- `Dockerfile`: `python:3.12-slim-bullseye` をベースに bot コンテナをビルドする。ロケール（`ja_JP.UTF-8`）とタイムゾーン（`Asia/Tokyo`）を設定し、非特権ユーザー `appuser` で `python -m app.main` を実行する。
- `docker-compose.yml`: `disbot`（bot）と `db`（PostgreSQL 16）の2サービスを定義する。両サービスが `app/.env` を読み込む。設定は名前付きボリューム `pgdata` に永続化する。
