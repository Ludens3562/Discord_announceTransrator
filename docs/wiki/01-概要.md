# 概要
Discord Announce Translator は、Discord の監視対象チャンネルに投稿されたメッセージを翻訳し、同じチャンネルへ返信する Discord bot である。翻訳エンジン（プロバイダー）を切り替えられ、設定はギルド（サーバー）単位で PostgreSQL に永続化する。

## プロジェクトの目的
多言語が混在するチャンネルで、投稿の内容を自動的に指定言語へ翻訳して共有することを目的とする。ギルド管理者はチャンネル単位で翻訳を有効化し、言語・敬語レベル・翻訳プロバイダーを設定できる。

## 主要機能
現在の実装が提供する機能を次に示す。

- メッセージの自動翻訳と返信。監視対象チャンネルの投稿を翻訳し、元メッセージへ返信する（`app/message_handler.py`）。
- 翻訳プロバイダーの切替。DeepL と Google 翻訳を `Provider` インターフェースで抽象化し、ギルド既定とチャンネル上書きの2段階で選択する。
- マルチギルド、マルチチャンネル対応。ギルドごと、チャンネルごとに設定を保持する。
- Markdown とメンションの保護。コードブロック、インラインコード、Discord メンション、カスタム絵文字、URL を翻訳対象から除外する（`app/utils/markdown_helper.py`）。
- スラッシュコマンドによる運用。監視チャンネル管理、言語設定、手動翻訳、翻訳テスト、DeepL 使用量表示、コマンド同期を提供する（`app/commands/translate_group.py`）。
- 設定の永続化。ギルド設定と監視チャンネルを PostgreSQL に保存し、bot 起動時にスキーマを自動作成する（`app/db/`）。

## アーキテクチャパターン
レイヤードアーキテクチャを採用する。責務を次のレイヤーに分離する。

- エントリーポイント層: 環境変数を読み込み bot を起動する（`app/main.py`）。
- bot 層: Discord イベントを受け取り、依存を初期化する（`app/bot.py`）。
- コマンド層: スラッシュコマンドを定義する（`app/commands/`）。
- サービス層: 翻訳パイプラインを提供する（`app/translation_service.py`）。
- プロバイダー層: 翻訳エンジンを抽象化する（`app/providers/`）。
- 永続化層: 設定の CRUD（作成、参照、更新、削除）を提供する（`app/db/`）。
- ユーティリティ層: Markdown 保護と認証チェックを提供する（`app/utils/`）。

依存の初期化は同期的なコンストラクタではなく、discord.py の非同期フック `setup_hook` で行う。詳細は [アーキテクチャ](./03-アーキテクチャ.md) を参照する。
