# コマンドリファレンス
`/translate` スラッシュコマンドの一覧、引数、権限を示す。定義は `app/commands/translate_group.py` に基づく。

## コマンド階層
`translate` グループの配下に、`channel` / `config` サブグループと、直下のコマンドを持つ。

```text
/translate
├── channel
│   ├── add
│   ├── remove
│   ├── list
│   └── provider
├── config
│   ├── language
│   ├── formality
│   ├── provider
│   └── show
├── manual
├── test
├── usage
└── sync
```

## 権限
コマンドは `app_commands.check` デコレータで権限を検証する。権限の判定は `app/utils/auth.py` の関数で行う。

- サーバー管理権限（Manage Server）または bot オーナー: `channel` および `config` の各コマンド、`manual`、`test`、`usage`。判定は `is_guild_admin_check`。
- bot オーナーのみ: `sync`。判定は `is_owner_check`。

権限が不足する場合は、共通エラーハンドラ `handle_app_command_error` が「この操作にはサーバー管理権限またはBOTオーナー権限が必要です。」というメッセージを返す（`app/commands/translate_group.py:509-529`）。

## channel サブグループ
監視チャンネルを管理する。

### /translate channel add
監視チャンネルを追加する。

- 引数: `channel`（任意、テキストチャンネル）。省略時は実行チャンネルを対象とする。
- 応答: 追加した場合と、既に監視対象だった場合で異なるメッセージを返す。
- 制約: ギルド内でのみ使用できる。対象がテキストチャンネルでない場合はエラーを返す。

### /translate channel remove
監視チャンネルを削除する。

- 引数: `channel`（任意、テキストチャンネル）。省略時は実行チャンネルを対象とする。
- 応答: 削除した場合と、監視対象でなかった場合で異なるメッセージを返す。

### /translate channel list
ギルド内の監視チャンネル一覧を Embed で表示する。

- 引数: なし。
- 応答: 監視チャンネルのメンション一覧。未設定の場合はその旨を表示する。取得できないチャンネルは「不明なチャンネル (ID)」と表示する。

### /translate channel provider
チャンネル単位のプロバイダー上書きを設定または解除する。

- 引数: `provider`（必須、`deepl` / `google` / `clear`）、`channel`（任意）。`clear` を指定すると上書きを解除する。
- 応答: `clear` 以外は登録済みプロバイダーか検証する。監視対象外のチャンネルには設定できず、先に追加を促すメッセージを返す。

## config サブグループ
ギルド単位の翻訳設定を管理する。

### /translate config language
翻訳元・翻訳先言語を設定する。

- 引数: `source_lang`（必須）、`target_lang`（必須）。いずれも大文字へ変換して保存する。
- 応答: 設定内容（`翻訳設定を更新しました: EN → JA` など）を返す。

### /translate config formality
翻訳の敬語レベルを設定する。

- 引数: `formality`（必須、`default` / `more` / `less` / `prefer_more` / `prefer_less`）。
- 応答: 設定した敬語レベルを返す。設定値は保存されるが、現在の翻訳呼び出しには渡していない（[データモデル](./05-データモデル.md) を参照）。

### /translate config provider
ギルドの既定翻訳プロバイダーを設定する。

- 引数: `provider`（必須、`deepl` / `google`）。
- 応答: 登録済みプロバイダーか検証したうえで設定内容を返す。

### /translate config show
現在のギルド設定と監視チャンネル情報を Embed で表示する。

- 引数: なし。
- 応答（Embed のフィールド）: 翻訳元言語、翻訳先言語、敬語レベル、既定プロバイダー、監視チャンネル数、DeepL API キーの設定有無、Google 翻訳の利用可否。実行者のみに表示する（ephemeral）。

## 直下のコマンド
グループ直下のコマンドを示す。

### /translate manual
メッセージIDを指定して手動翻訳し、結果を Embed で表示する。

- 引数: `message_id`（必須、数字の文字列）、`channel`（任意）。
- 設定の解決: 対象チャンネルが監視対象ならその解決済み設定を用いる。監視対象外の場合はギルド既定設定へフォールバックする。
- 応答（Embed）: 作成者、チャンネル、投稿日時、原文（先頭1024文字）、翻訳結果（先頭1024文字）、元メッセージへのリンク。
- エラー: メッセージ未検出、アクセス権限なし、翻訳可能テキストなし、翻訳失敗をそれぞれ通知する。

### /translate test
入力テキストをギルド設定で翻訳し、結果を返す。

- 引数: `text`（必須）。
- 応答: 原文と翻訳結果を実行者のみに表示する（ephemeral）。翻訳失敗時はエラー内容を返す。

### /translate usage
DeepL API の文字数使用量を Embed で表示する。

- 引数: なし。
- 前提: `DEEPL_API_KEY` が設定されていること。未設定の場合はその旨を通知する。
- 応答（Embed）: 使用文字数、上限文字数、使用率。使用量には数分の遅延がある場合がある旨をフッターに記載する。

### /translate sync
スラッシュコマンドツリーを手動同期する。bot オーナーのみ実行できる。

- 引数: `scope`（任意、`guild` / `global`、既定 `guild`）。
- `guild`: 現在のギルドへ同期する。ギルド内でのみ使用できる。
- `global`: 全体へ同期する。反映には最大1時間かかる場合がある。
- 応答: 同期したコマンド数を実行者のみに表示する（ephemeral）。
