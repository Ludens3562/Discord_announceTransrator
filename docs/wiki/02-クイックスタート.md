# クイックスタート
Docker Compose を用いて PostgreSQL と bot を起動し、監視チャンネルを登録するまでの手順を示す。作業ディレクトリはリポジトリルート（`docker-compose.yml` があるディレクトリ）とする。

## 前提条件
次を満たしていること。

- Docker Engine と Docker Compose が利用できること。
- Discord Developer Portal で bot を作成し、bot トークンを取得済みであること。
- bot の招待時に `applications.commands` と、メッセージ閲覧・送信に必要な権限を付与していること。
- bot の特権インテントのうち Message Content Intent を有効化していること。実装では `discord.Intents.default()` に加えて `message_content` を有効化する（`app/bot.py:41-42`）。
- DeepL を利用する場合は DeepL API キーを取得済みであること。Google 翻訳のみを利用する場合は API キーは不要である。

## 初回セットアップ
次の順で設定する。

1. 環境変数テンプレートをコピーする。`app/.env.example` を `app/.env` にコピーする。`app/.env` は `.gitignore` 済みのためコミットしない。

   ```bash
   cp app/.env.example app/.env
   ```

2. `app/.env` を編集し、次の環境変数を設定する。値の意味は次のとおりである。

   | 環境変数 | 必須 | 既定値（テンプレート） | 説明 |
   | --- | --- | --- | --- |
   | `BOT_TOKEN` | 必須 | 空 | Discord bot トークン |
   | `DEEPL_API_KEY` | 条件付き | 空 | DeepL API キー。未設定時は DeepL プロバイダーを無効化する |
   | `DEV_GUILD_ID` | 任意 | 空 | 設定するとそのギルドにのみコマンドを即時同期する。省略時はグローバル同期 |
   | `POSTGRES_HOST` | 必須 | `db` | PostgreSQL ホスト名。Docker Compose 利用時はサービス名 `db` |
   | `POSTGRES_PORT` | 任意 | `5432` | PostgreSQL ポート番号。整数で指定する |
   | `POSTGRES_USER` | 必須 | `disbot` | PostgreSQL ユーザー名 |
   | `POSTGRES_PASSWORD` | 必須 | `change_me` | PostgreSQL パスワード。運用時は変更する |
   | `POSTGRES_DB` | 必須 | `disbot` | PostgreSQL データベース名 |

3. PostgreSQL と bot を起動する。

   ```bash
   docker compose up -d --build
   ```

   `db` サービスがヘルスチェックに合格した後に `disbot` サービスが起動する。bot は起動時に必要なテーブル（`guild_settings`、`monitored_channels`）を自動作成する（`app/db/pool.py:111-121`）。

## 動作確認
起動後、サーバー管理権限（Manage Server）を持つメンバー、または bot オーナーとして次を実行する。コマンドは Discord クライアントのメッセージ入力欄に入力する。

1. 現在の設定を表示する。

   ```text
   /translate config show
   ```

2. 監視チャンネルを追加する。実行チャンネルを対象にする場合は引数を省略する。

   ```text
   /translate channel add
   ```

3. ギルドの翻訳元・翻訳先言語を設定する。次は英語から日本語への設定例である。

   ```text
   /translate config language source_lang:EN target_lang:JA
   ```

4. 監視チャンネルへメッセージを投稿し、翻訳結果が返信されることを確認する。

## プロバイダーの切替
ギルド既定プロバイダーと、チャンネル単位の上書きを設定できる。

- ギルド既定プロバイダーを DeepL にする。

  ```text
  /translate config provider provider:deepl
  ```

- 特定チャンネルのみ Google 翻訳に上書きする。上書きを解除する場合は `provider:clear` を指定する。

  ```text
  /translate channel provider provider:google
  ```

コマンドの全一覧と権限は [コマンドリファレンス](./08-コマンドリファレンス.md) を参照する。デプロイと運用の詳細は [デプロイメント](./10-デプロイメント.md) を参照する。
