# コアコンポーネント
主要なクラスと関数の実装を、レイヤーごとに解説する。ソースコードの参照はリポジトリルートからの相対パスと行番号で示す。

## エントリーポイント（app/main.py）
`main` は環境変数を読み込み、`TranslatorBot` を生成して起動する（[../../app/main.py:21-38](../../app/main.py#L21-L38)）。

- ロギングを `INFO` レベルで初期化する。
- `app/.env` を明示的なパスで読み込む（`Path(__file__).resolve().parent / ".env"`）。
- `BOT_TOKEN` が未設定の場合はエラーログを出力して終了する。
- `python -m app.main` として実行する。

## TranslatorBot（app/bot.py）
`TranslatorBot` は `discord.ext.commands.Bot` を継承した bot 本体である（[../../app/bot.py:30-118](../../app/bot.py#L30-L118)）。同期的な外部 I/O をコンストラクタに持たせない設計とする。

主なメソッドを次に示す。

- `__init__`: インテントを設定する。`message_content` を有効化し、依存（`pool`、`repository`、`translation_service`）を `None` で初期化する。
- `setup_hook`: 非同期初期化フック。接続プールの生成、スキーマ初期化、`ConfigRepository` と `TranslationService` の生成、コマンドツリーへの `TranslateGroup` 追加、エラーハンドラ登録を行う。
- `_build_providers`: 環境変数に応じてプロバイダー辞書を構築する。`DEEPL_API_KEY` があれば `DeepLProvider` を登録し、`GoogleProvider` は常に登録する（[../../app/bot.py:60-78](../../app/bot.py#L60-L78)）。
- `on_ready`: プレゼンスを設定し、コマンドを同期する。`DEV_GUILD_ID` があればそのギルドへ即時同期し、無ければグローバル同期する。
- `on_message`: 送信者が bot 自身、または依存が未初期化の場合は何もしない。それ以外は `translate_and_reply` へ委譲する。
- `close`: 接続プールを閉じてから親クラスの `close` を呼ぶ。

## メッセージ処理（app/message_handler.py）
`translate_and_reply` は監視対象メッセージを翻訳して返信する非同期関数である（[../../app/message_handler.py:20-63](../../app/message_handler.py#L20-L63)）。bot 本体から分離し、単体テストで直接呼び出せる純粋な関数として実装する。

処理の流れは次のとおりである。

1. ギルド外（DM など）や空メッセージは対象外として終了する。
2. `get_channel_translation_settings` で解決済み設定を取得する。監視対象外（`None`）なら終了する。
3. `translate_text` で翻訳する。`ProviderError` は警告ログを出力して終了する。
4. 翻訳結果が空なら終了する。
5. `message.reply(translation, mention_author=False)` で返信する。返信時に送信者へメンションしない。`discord.HTTPException` は警告ログを出力する。

## TranslationService（app/translation_service.py）
`TranslationService` は翻訳パイプラインを提供するクラスである（[../../app/translation_service.py:12-142](../../app/translation_service.py#L12-L142)）。詳細は [翻訳パイプライン](./07-翻訳パイプライン.md) を参照する。

主なメソッドを次に示す。

- `__init__`: プロバイダー辞書と、任意の同時実行上限 `max_concurrent` を受け取る。`max_concurrent` を指定した場合は `asyncio.BoundedSemaphore` で同時実行数を制限する。
- `translate_text`: Markdown 保護 → プロバイダー呼び出し → 復元の順で処理する。`provider_name` が `None` の場合は登録された最初のプロバイダーを用いる。
- `translate_embed`: Embed の `title` / `description` / `fields` / `footer.text` を翻訳し、色やタイムスタンプを維持した新しい Embed を返す。
- `translate_message`: `discord.Message` の `content` と `embeds` を翻訳し、辞書で返す。
- `_call_provider`: プロバイダー呼び出しラッパー。`translate_async` があれば `await` し、無ければ同期 `translate` を `asyncio.to_thread` で実行する。プロバイダー固有の例外は `ProviderError` に変換して伝搬する。

## プロバイダー層（app/providers/）
翻訳エンジンを `Provider` 抽象で統一する。

- `Provider`（[../../app/providers/provider.py:24-51](../../app/providers/provider.py#L24-L51)）: 抽象基底クラス。`translate` メソッドの実装を義務付ける。正常時は翻訳文字列を返し、失敗時は `ProviderError` を投げる契約とする。
- `ProviderError`（[../../app/providers/provider.py:14-21](../../app/providers/provider.py#L14-L21)）: プロバイダー固有の失敗を上位へ伝搬する例外。
- `DeepLProvider`（[../../app/providers/deepl_provider.py:8-38](../../app/providers/deepl_provider.py#L8-L38)）: DeepL API を利用する。コンストラクタでは API キーを保持するのみで外部呼び出しはしない。`translate` で `deepl.Translator` を生成し、`tag_handling="xml"` を指定して呼び出す。`translate_async` は同期呼び出しを別スレッドで実行する。
- `GoogleProvider`（[../../app/providers/google_provider.py:7-33](../../app/providers/google_provider.py#L7-L33)）: googletrans を利用する。API キーは不要である。引数名は googletrans の仕様に合わせて `src` / `dest` を用いる。

## 永続化層（app/db/）
PostgreSQL への接続とデータアクセスを提供する。

- `create_pool`（[../../app/db/pool.py:52-108](../../app/db/pool.py#L52-L108)）: 環境変数から接続プールを生成する。必須の環境変数が不足する場合や、ポート番号が整数でない場合は `DatabaseConfigurationError` を投げる。プールサイズは最小1、最大5とする。
- `init_schema`（[../../app/db/pool.py:111-121](../../app/db/pool.py#L111-L121)）: テーブルとインデックスをトランザクション内で冪等に作成する。
- `ConfigRepository`（[../../app/db/repository.py:26-267](../../app/db/repository.py#L26-L267)）: 設定の CRUD を提供する。`get_channel_translation_settings` は結合クエリで解決済み設定を1回で取得する。`add_monitored_channel` / `remove_monitored_channel` / `set_channel_provider_override` は操作結果を真偽値で返す。`get_guild_settings` は行が無い場合に既定値を返し、レコードは新規作成しない（遅延作成）。`upsert_guild_language` / `upsert_guild_formality` / `upsert_guild_provider` は `INSERT ... ON CONFLICT DO UPDATE` で更新する。

## ユーティリティ層（app/utils/）
横断的なユーティリティを提供する。

- `markdown_helper`（[../../app/utils/markdown_helper.py](../../app/utils/markdown_helper.py)）: `protect_text` は翻訳から除外すべき部分をプレースホルダに置換し、`restore_text` で元に戻す。詳細は [翻訳パイプライン](./07-翻訳パイプライン.md) を参照する。
- `auth`（[../../app/utils/auth.py:10-42](../../app/utils/auth.py#L10-L42)）: `is_owner_check` は bot オーナーか判定する。`is_guild_admin_check` は bot オーナー、またはギルドで `manage_guild`（サーバー管理）権限を持つメンバーを許可する。DM やメンバー以外のユーザーは拒否する。
